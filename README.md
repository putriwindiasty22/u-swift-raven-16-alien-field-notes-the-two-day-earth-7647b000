One line from an alien tourist reviewing Earth: a 40-light-year trip for the oceans, won over by humans apologising to the chairs they bump into — and a gift shop selling the planet back as a snow globe. A single-line review of 167 characters, well inside the gate's 1–200 character limit.

The program is deterministic: it always writes the same line to `/output/entry.txt`, with no setup the reader has to assemble — the punch lands at the end.

## Run it

```sh
node main.ts
```
